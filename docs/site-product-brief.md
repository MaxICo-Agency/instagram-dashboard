## 3. Що всередині — 9 вкладок

| Вкладка | Що дає |
|---|---|
| 📊 **Огляд** | KPI з вибором періоду **7 / 30 / 90 днів / весь час** і **порівнянням із попереднім періодом**, кращий день/час/формат, графік переглядів, топ-пости (клікабельні) |

| 👥 **Підписники** | Щоденний приріст із відмітками днів Reels, кореляція «перегляди → приріст» |

| 🧠 **Паттерни** | На основі Whisper-транскриптів: довжина скрипта vs перегляди, питання в хуку, розмовність, слова-магніти / слова-збереження |

| 🤖 **AI-поради** | Рекомендації LLM на основі твоїх метрик (Контент / Формат / Час / Аудиторія / Stories) |

## 4. AI-можливості

- **🎙 Whisper-транскрипт.** Дашборд завантажує кожен Reel і розшифровує мову (OpenAI Whisper). Транскрипти зберігаються — на них працюють Паттерни, Скрипти й Генератор.
- **✨ Генератор скриптів.** Аналізує твої топ-рилси та паттерни мовлення і пише новий скрипт у твоїй манері (хук → повний скрипт → розбір).
- **🤖 AI-поради.** LLM формує конкретні рекомендації з прив'язкою до твоїх чисел.

> 💰 **Орієнтовна вартість AI:** Whisper ≈ $0.006/хв аудіо, рекомендації/генерація — копійки за запит (модель `gpt-4.1`). Ключ OpenAI — клієнта.

## 5. Як це працює (схема для інфографіки)

```
Instagram Graph API  →  Дашборд (Next.js)  →  кеш 10 хв
        │                      │
        │                      ├─ метрики й аналітика (миттєво, без запитів на кожен клік)
        │                      ├─ Whisper-транскрипти (зберігаються)
        │                      └─ OpenAI: рекомендації + генератор скриптів
        └─ токен акаунта (вводиться в ⚙ Налаштуваннях)
```

Дані тягнуться паралельно й кешуються — сторінка відкривається швидко, а ліміти API не перевищуються.

## 6. Підключення Instagram за 10 хв (покроково)

> Повна інструкція зі скриншотами додається окремим PDF (у репозиторії: `docs/Instagram-Dashboard-Інструкція.pdf`).

1. Акаунт Instagram має бути **Business** або **Creator** і прив'язаний до сторінки Facebook.
2. У Meta-апі (developers.facebook.com) → сценарій **«Manage messaging & content on Instagram»**.
3. Додати дозвіл **`instagram_business_manage_insights`**.
4. Згенерувати токен доступу для акаунта.
5. Відкрити дашборд → **⚙ Налаштування → API-ключі** → вставити токен + OpenAI-ключ → **Зберегти**.

Готово — дашборд показує реальні дані.

## 7. Розгортання

| Варіант | Кому | Як |
|---|---|---|
| 🖥 **Локально** | для тесту | `pnpm install` → `cp .env.example .env.local` → `pnpm dev` → `localhost:3000` |
| ☁️ **На сервері** | постійний доступ за посиланням | Docker + Traefik (HTTPS Let's Encrypt), 1 команда `docker compose up -d --build` |
| 🤝 **«Під ключ» від MaxICo** | хто не хоче технічних деталей | Розгортаємо на піддомені клієнта, підключаємо акаунт, навчаємо |

Ключі (Instagram-токен, OpenAI) додаються **прямо в інтерфейсі** (⚙ Налаштування) — без редеплою.

## 8. Технології

Next.js 16 (App Router, TypeScript) · Tailwind CSS v4 · Recharts · OpenAI (chat + Whisper) · Docker + Traefik. Збереження — у файлі на Docker-volume, **без зовнішньої БД**.

## 9. Доступи, ліміти, безпека (блок «зелене/фіолетове», як у референсі)

- 🟢 **Адмін-вхід** — кожна сторінка і кожен API за логіном/паролем (підписаний cookie). Неавторизовані → 401 / редірект.
- 🟢 **Секрети** — лише в `.env` або на сервері, ніколи не в коді/репозиторії.
- 🟣 **Ліміт Instagram API** — ~200 запитів/год на акаунт → дашборд кешує дані (10 хв) і не б'є API зайвий раз.
- 🟣 **App Review** потрібен лише для роботи з *чужими* акаунтами у проді; для власного акаунта працює одразу.
- 🔒 `noindex` на всіх сторінках.
